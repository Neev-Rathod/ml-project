## Project Overview

Standard supervised ML assumes abundant, clean labels. Real clinical datasets have a small
**Gold Set** (human-verified) alongside a large **Untrusted Pool** (machine-labeled or unlabeled)
with structured noise and sensor artifacts. This project studies three strategies to handle this:

1. **Graph Label Propagation** (WP3) – discard noisy labels, spread gold labels via kNN graph
2. **Multi-View Co-Training & TSVMs** (WP4) – train paired classifiers across independent signal views
3. **Latent-Noise EM** (WP5) – keep noisy labels, model true class as hidden variable

Evaluated on a **Synthetic Data Suite** (WP2) and the **PTB-XL 12-Lead ECG Dataset** (21,799 waveforms).

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure the dataset path

Every WP script reads the path from the environment variable `PTBXL_PATH` (or you can
pass `--data_path` on the CLI). Set it once:

```bash
# Windows
set PTBXL_PATH=D:\ml-project\dataset

# Linux / macOS
export PTBXL_PATH=/path/to/ptbxl
```

### 3. Run WP1 first (everyone depends on the feature matrix it produces)

```bash
cd wp1_data_pipeline
python run_wp1.py --data_path D:\ml-project\dataset --out_dir ..\outputs\wp1
```

This produces `outputs/wp1/features.npz` and `outputs/wp1/labels.npz` which the other WPs load.

## Data Split Protocol

| Fold | Usage                                                               |
| ---- | ------------------------------------------------------------------- |
| 1–8  | Training (split into Gold Set D_L and Untrusted Pool D_U)           |
| 9    | Validation / hyperparameter tuning                                  |
| 10   | Test (clean gold records only – **never touch during development**) |

Gold Set (D_L): records where `validated_by_human == True` **and** confidence = 100%.  
Untrusted Pool (D_U): records where `initial_autogenerated_report == True` or `validated_by_human == False`.

## Evaluation Metrics (from proposal §5.5)

- Macro-averaged F1 and per-class F1
- One-vs-Rest ROC-AUC
- Precision-Recall AUC
- Confusion matrix recovery error ‖T̂ − T_true‖\_F (synthetic only)
